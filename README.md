# Personal Finance Dashboard

A modern, responsive personal finance dashboard built with React and TypeScript. This application helps users track their expenses, income, budgets, and financial goals in a clean and intuitive interface.

## 🚀 Features

- **Dashboard Overview**
  - Real-time financial summary
  - Monthly income vs expenses visualization
  - Budget tracking and progress
  - Savings goals monitoring
  - Recent transactions list

- **Transaction Management**
  - Add, edit, and delete transactions
  - Categorize transactions
  - Filter transactions by date, category, and type
  - Search functionality for transactions

- **Budget Tracking**
  - Set monthly budgets for different categories
  - Visual progress tracking
  - Budget utilization alerts
  - Category-wise spending analysis

- **Financial Analytics**
  - Monthly income vs expenses chart
  - Category-wise spending distribution
  - Savings growth tracking
  - Financial health indicators

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: CSS Modules
- **State Management**: React Context API
- **Data Visualization**: Custom charts and graphs
- **Local Storage**: For data persistence

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## 📝 Notes

- All data is currently stored in local storage
- The application is designed to be responsive across different screen sizes
- TypeScript is used throughout the project for type safety
